# SET Trader skill: ชุดสกิลเทรดหุ้นไทยรายวันสำหรับ Claude

ดัดแปลงจาก [day-trader-skill](https://github.com/Jakeschincariol/day-trader-skill)
(MIT) ให้ใช้กับตลาดหลักทรัพย์แห่งประเทศไทย (SET) โดยเฉพาะ ใช้เวลากรุงเทพฯ
มีพักเที่ยง วันหยุดของ SET ช่วงราคา (tick size) และล็อตละ 100 หุ้น
เขียนด้วย Python มาตรฐาน ไม่ต้องติดตั้งอะไรเพิ่ม ไม่ต้องใช้ API key
ข้อมูลราคามาจาก Yahoo Finance ฟรี (PTT → PTT.BK)

**ชุดนี้ไม่ส่งคำสั่งซื้อขายเอง** คุณต้องพิมพ์คำสั่งในแอปโบรกเกอร์ของคุณเอง

## 5 สกิล

| คำสั่ง | หน้าที่ |
| --- | --- |
| `/set-scanner` | สแกนหุ้นไทย 89 ตัว (หรือรายชื่อของคุณ): เบรคจุดสูงสุด 20 วัน, กลับขึ้นเหนือเส้นเฉลี่ย 20 วัน, RSI ต่ำกว่า 30, เด้งจากจุด oversold และ opening-range breakout ระหว่างวัน |
| `/set-entry` | เฝ้าหุ้นทีละแท่ง 5 นาที บอกตอนที่แท่งปิดเหนือกรอบราคา 15 นาทีแรก (10:00-10:15) |
| `/set-exit` | ตั้งจุดตัดขาดทุนและเป้าขายก่อนซื้อ ปัดราคาให้ตรงช่วงราคาของหุ้นตัวนั้น ตรวจ ceiling/floor ±30 % |
| `/set-timemachine` | จำลองการเทรดที่เหลือของวัน 10,000 รอบจากแท่ง 5 นาทีย้อนหลัง 60 วันของหุ้นตัวนั้น และทดสอบกฎเดียวกันกับทุกวันที่ผ่านมา |
| `/set-budget` | คำนวณจำนวนหุ้น (เป็นล็อต 100) จากเงินทุนและขาดทุนสูงสุดต่อไม้ **รวมค่าธรรมเนียมทั้งขาซื้อและขาขาย** ตรวจกฎทุกข้อ (PASS/BLOCK) แล้วออกตั๋วคำสั่งให้คุณพิมพ์เอง |

ลำดับการใช้: `scanner → entry → exit → timemachine → budget`

## ติดตั้ง

```bash
cp -r set-* ~/.claude/skills/
```

หรือติดตั้งเป็นปลั๊กอิน (โฟลเดอร์นี้มี `.claude-plugin/`):

```
/plugin marketplace add ./set-trader-skill
/plugin install set-trader-skill@set-trader-skill
```

ต้องใช้ Python 3.8 ขึ้นไป ทดสอบได้แบบออฟไลน์:

```bash
python3 -m unittest discover -s tests -v
```

## ตัวอย่างจริง: PTT วันที่ 16 พฤศจิกายน 2026

1. **`/set-entry`**: กรอบ 15 นาทีแรก 38.20–38.50 แท่ง 11:20 ปิด 38.60 เหนือกรอบ → TRIGGERED 11:25
2. **`/set-exit`**: ช่วงราคาของ PTT อ่านจากราคาจริงได้ 0.05 จุดตัดขาดทุน 38.35 (กลางกรอบ)
   เป้า 39.10 (2R) ห่าง 5 และ 10 ช่องราคา
3. **`/set-timemachine`**: 10,000 รอบ ถึงเป้าก่อน 31.6 % โดนตัดขาดทุนก่อน 68.3 %
   จุดคุ้มทุนของ 2R คือ 33.3 % สรุป "ใกล้คุ้มทุน" กฎเดียวกันย้อนหลัง 58 วัน
   เกิดสัญญาณ 14 ครั้ง ถึงเป้า 0 ครั้ง
4. **`/set-budget`**: เงินทุน 100,000 ขาดทุนสูงสุด 1,000 ต่อไม้ ได้ 1,200 หุ้น
   (จำกัดด้วยเพดาน 50 % ของพอร์ต) ขาดทุนถ้าโดน stop ประมาณ 457 บาท รวมค่าธรรมเนียม
   แต่ **BLOCK** เพราะหลังหักค่าธรรมเนียม 0.17 % ต่อขา กำไรต่อความเสี่ยงเหลือแค่ 0.97R

ข้อ 4 คือบทเรียนสำคัญของหุ้นไทย ไม้สั้น ๆ ระหว่างวันโดนค่าธรรมเนียมกินกำไรมาก

## ข้อเท็จจริงของตลาดที่ใช้ (และจุดที่ต้องระวัง)

- **เวลาซื้อขาย** (กรุงเทพฯ): เช้า 10:00–12:30 บ่าย 14:00–16:30 ATC 16:30–16:40
  ยืนยันจากแท่ง 5 นาทีของ Yahoo (61 แท่งต่อวัน: 10:00–12:25 และ 13:55–16:25)
- **วันหยุด**: ปี 2026 ตรวจกับวันที่ไม่มีการซื้อขายจริงของ PTT, ADVANC และ KBANK แล้ว
  ส่วน 7, 10 และ 31 ธ.ค. 2026 เป็นวันที่คาดว่าจะหยุดแต่ยังไม่ยืนยัน ปี 2027 ยังไม่มีในไฟล์
  เพิ่มเองได้ที่ `trader-set/holidays.json`
- **ช่วงราคา (tick size)**: ข้อมูลจริงปี 2026 แสดงว่า SET ใช้ช่วงราคาละเอียดกว่าตารางเดิมกับหุ้นบางตัว
  (PTT ที่ 38 บาทขยับทีละ 0.05 แต่ IVL ที่ 28 บาทขยับทีละ 0.25) เครื่องมือจึงอ่านช่วงราคาจากราคาซื้อขายล่าสุดของหุ้นแต่ละตัว
  กำหนดเองได้ใน `config.json` (`"ticks": {"PTT": 0.05}`) **ตรวจในแอปโบรกเกอร์ทุกครั้ง**
- **ล็อต**: 100 หุ้น (`board_lot`) ราคาเพดาน/พื้น ±30 % ของราคาปิดวันก่อน (`price_limit_pct`)
- **ค่าธรรมเนียม**: ค่าเริ่มต้น 0.17 % ต่อขา (ค่าคอมมิชชัน + VAT 7 % + ค่าธรรมเนียมตลาด)
  แต่ละโบรกเกอร์ไม่เท่ากัน ตั้งของคุณที่ `fee_rate_pct`
- **ข้อมูลล่าช้า**: แท่งราคา SET จาก Yahoo ช้าประมาณ 15–25 นาทีตอนทดสอบ
  ห้ามใช้แทนราคาจริง ตรวจราคาในแอปโบรกเกอร์ก่อนส่งคำสั่งเสมอ
- **ซื้ออย่างเดียว (long)** ไม่มี short selling ไม่มี margin

## ไม่ได้ทำ (เทียบกับชุดเดิม)

ตัดสกิลที่ผูกกับสหรัฐฯ ออก: ข่าวจาก SEC, งบการเงินจาก SEC, การซื้อขายของสภาคองเกรส
และการส่งคำสั่งผ่าน Alpaca (ไม่มีหุ้นไทย) รายชื่อหุ้นจาก set.or.th ดึงอัตโนมัติไม่ได้
(เว็บบล็อกบอท) จึงใช้ไฟล์ `universe.txt` แทน

## ข้อควรรู้

**ไม่ใช่คำแนะนำการลงทุน** เป็นซอฟต์แวร์ที่อ่านข้อมูลสาธารณะแล้วคำนวณเท่านั้น
คนเทรดรายวันส่วนใหญ่ขาดทุน Time Machine เป็นการจำลองจากข้อมูล 60 วัน ไม่ใช่การพยากรณ์
จุดตัดขาดทุนเป็นแผน ไม่ใช่การรับประกัน ถ้าราคากระโดดอาจได้ราคาแย่กว่านั้น
